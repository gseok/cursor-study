# Pygame 오셀로 게임

pygame을 사용하여 구현한 오셀로(Othello) 게임입니다.

## 게임 규칙

오셀로는 8x8 보드에서 진행되는 전략 게임입니다:

1. **게임 시작**: 보드 중앙에 4개의 돌이 교차로 배치됩니다
   - 흑돌(검은색)과 백돌(흰색)이 각각 2개씩
   
2. **게임 진행**: 
   - 흑돌이 먼저 시작합니다
   - 상대방의 돌을 양쪽에서 둘러싸면 그 돌들을 뒤집을 수 있습니다
   - 유효한 수가 없으면 턴을 건너뜁니다
   
3. **게임 종료**: 
   - 보드가 가득 차거나 양쪽 모두 수를 둘 수 없을 때
   - 더 많은 돌을 가진 플레이어가 승리합니다

## 설치 및 실행

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 게임 실행
```bash
python othello.py
```

## 게임 조작법

- **마우스 클릭**: 돌을 놓을 위치를 선택
- **R키**: 게임 재시작
- **ESC 또는 창 닫기**: 게임 종료

## 게임 화면 설명

- **보드**: 8x8 격자로 구성된 게임 보드
- **빨간 점**: 흑돌이 놓을 수 있는 유효한 위치
- **파란 점**: 백돌이 놓을 수 있는 유효한 위치
- **점수 표시**: 현재 흑돌과 백돌의 개수
- **현재 플레이어**: 누구 차례인지 표시

## 게임 특징

- **실시간 유효한 수 표시**: 놓을 수 있는 위치를 시각적으로 표시
- **자동 턴 관리**: 유효한 수가 없으면 자동으로 턴을 넘김
- **승부 판정**: 게임 종료 시 자동으로 승부를 판정
- **재시작 기능**: R키로 언제든지 게임을 재시작할 수 있음

## 기술 스택

- **Python 3.x**
- **Pygame 2.1.0+**: 게임 그래픽 및 이벤트 처리

## 게임 스크린샷

게임을 실행하면 다음과 같은 화면을 볼 수 있습니다:
- 초록색 배경의 8x8 보드
- 중앙에 초기 4개 돌 배치

- 유효한 수 위치에 색상 점으로 표시
