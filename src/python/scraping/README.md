# KBO 팀 순위 스크래핑

KBO(한국야구위원회) 홈페이지에서 팀 순위 정보를 스크래핑하는 Python 스크립트입니다.

## 기능

- KBO 홈페이지에서 실시간 팀 순위 정보 수집
- 팀명, 경기 수, 승패, 승률, 게임차, 연속 기록 정보 추출
- 콘솔에 보기 좋게 포맷팅된 결과 출력
- JSON 파일로 데이터 저장
- Selenium을 사용한 JavaScript 렌더링 지원

## 설치

```bash
pip install -r requirements.txt
```

**주의**: 이 스크립트는 Selenium을 사용하므로 Chrome 브라우저가 설치되어 있어야 합니다. ChromeDriver는 자동으로 다운로드됩니다.

## 사용법

```bash
python3 kbo_team_ranking.py
```

## 파일 구조

- `kbo_team_ranking.py`: 메인 스크래핑 스크립트
- `requirements.txt`: 필요한 Python 패키지 목록
- `README.md`: 사용 설명서

## 기술적 세부사항

- **Selenium WebDriver**: JavaScript로 동적으로 로드되는 데이터를 처리하기 위해 사용
- **BeautifulSoup**: HTML 파싱을 위해 사용
- **Chrome Headless 모드**: 브라우저 창을 띄우지 않고 백그라운드에서 실행
- **자동 ChromeDriver 관리**: webdriver-manager를 통해 ChromeDriver 자동 다운로드 및 관리

## 주의사항

- 웹사이트 구조가 변경될 경우 스크립트 수정이 필요할 수 있습니다.
- 과도한 요청으로 서버에 부하를 주지 않도록 적절한 간격을 두고 사용하세요.
- 스크래핑된 데이터는 참고용으로만 사용하시기 바랍니다.
- Chrome 브라우저가 설치되어 있어야 합니다.
- 첫 실행 시 ChromeDriver 다운로드로 인해 시간이 걸릴 수 있습니다.
