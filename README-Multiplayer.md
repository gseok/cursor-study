# 🌐 멀티플레이어 틱택토 게임

WebSocket을 사용한 실시간 멀티플레이어 틱택토 게임입니다.

## 🚀 실행 방법

### 1. 서버 실행

```bash
# 서버 디렉토리로 이동
cd server

# 의존성 설치
npm install

# 서버 실행
npm start
```

서버가 `http://localhost:8080`에서 실행됩니다.

### 2. 클라이언트 실행

```bash
# 메인 디렉토리에서
pnpm start
```

클라이언트가 `http://localhost:3000`에서 실행됩니다.

## 🎮 멀티플레이어 게임 방법

### 게임 시작하기
1. **시작 화면**에서 원하는 보드 크기 선택 (3×3 또는 4×4)
2. **🌐 온라인 멀티플레이어** 버튼 클릭
3. **플레이어 이름** 입력 후 "게임 참여" 클릭
4. **상대방 대기** 중... (다른 플레이어가 접속할 때까지)
5. **게임 시작!** 🎉

### 게임 플레이
- **실시간 대전**: 상대방의 움직임이 즉시 반영
- **턴 시스템**: 내 차례일 때만 클릭 가능
- **승부 결정**: 먼저 연결하는 플레이어가 승리
- **재경기**: 게임 종료 후 "다시 플레이" 버튼으로 새로운 상대 매칭

## 🔧 기술 구조

### 서버 (Node.js + WebSocket)
```
server/
├── server.js          # WebSocket 서버 메인
├── package.json        # 서버 의존성
└── README.md
```

**주요 기능:**
- **플레이어 매칭**: 같은 보드 크기를 원하는 플레이어 자동 매칭
- **게임 방 관리**: 각 게임별 독립적인 방 시스템
- **실시간 통신**: 게임 상태 실시간 동기화
- **연결 관리**: 플레이어 접속/해제 처리

## 📡 WebSocket 통신 프로토콜

### 클라이언트 → 서버
```javascript
// 플레이어 등록
{ type: 'JOIN', playerName: 'Player1' }

// 매치 찾기
{ type: 'FIND_MATCH', boardSize: 3, gameMode: 1 }

// 게임 움직임
{ type: 'MAKE_MOVE', position: 4 }

// 방 떠나기
{ type: 'LEAVE_ROOM' }
```

### 서버 → 클라이언트
```javascript
// 접속 완료
{ type: 'JOINED', playerId: 'abc123', playerName: 'Player1' }

// 상대방 대기
{ type: 'WAITING_FOR_OPPONENT', message: '상대방을 찾고 있습니다...' }

// 게임 시작
{ type: 'GAME_START', room: { id, players, boardSize, board, currentPlayer } }

// 게임 업데이트
{ type: 'GAME_UPDATE', room: {...}, move: { playerId, position, symbol } }

// 상대방 이탈
{ type: 'OPPONENT_LEFT', message: 'Player2님이 게임을 떠났습니다.' }
```

## 🎯 게임 로직

### 플레이어 매칭
1. **대기열 시스템**: 같은 설정(보드 크기)을 원하는 플레이어끼리 매칭
2. **즉시 매칭**: 대기 중인 플레이어가 있으면 즉시 게임 시작
3. **자동 대기**: 상대방이 없으면 대기열에 추가

### 게임 진행
1. **X 플레이어**: 먼저 접속한 플레이어
2. **O 플레이어**: 나중에 접속한 플레이어
3. **턴 시스템**: X부터 시작, 번갈아 가며 진행
4. **승리 조건**: 3×3는 3개 연결, 4×4는 4개 연결

### 연결 관리
- **자동 재연결**: 네트워크 끊김 시 자동으로 재연결 시도
- **상대방 이탈 처리**: 한 플레이어가 나가면 상대방에게 알림
- **방 정리**: 빈 방은 자동으로 삭제

## 🛠️ 개발 및 배포

### 개발 환경
```bash
# 서버 개발 모드 (nodemon)
cd server && npm run dev

# 클라이언트 개발 모드
pnpm start
```

### 환경 변수
클라이언트에서 WebSocket 서버 URL 설정:
```bash
# .env 파일
REACT_APP_WS_URL=ws://localhost:8080
```

### 배포 시 고려사항
1. **서버 배포**: Heroku, AWS, DigitalOcean 등
2. **WebSocket 지원**: 프록시 서버 설정 필요
3. **HTTPS/WSS**: 프로덕션에서는 보안 연결 사용
4. **스케일링**: 여러 서버 인스턴스 간 상태 공유 (Redis 등)
